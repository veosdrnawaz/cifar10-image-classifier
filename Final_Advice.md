# Final Advice — ML Project Checklist

---

## Abhi karne wale kaam:

1. **Streamlit app test karo** — image upload karke check karo ki prediction sahi aa rahi hai
2. **GitHub repo check karo** — sab files dikh rahi hain ya nahi

---

## Agla project start karne se pehle:

| Step | Kaam |
|------|------|
| 1 | Requirements finalize karo (dataset, model, UI, deployment) |
| 2 | Prompt file use karo — AI se pehle planning karao |
| 3 | Code likho aur har step pe run karo |
| 4 | Training preprocessing = UI preprocessing (same honi chahiye) |
| 5 | Local pe train → save → load → predict → UI sab chalao |
| 6 | Phir GitHub push karo aur deploy karo |
| 7 | Results save karo (accuracy, graphs, confusion matrix) |

---

## Yaad rakhne wali 3 cheezein:

1. **Credentials kabhi AI ko mat do**
2. **AI code blindly trust mat karo** — khud run karke verify karo
3. **Project sirf accuracy tak mat roko** — documentation + deployment zaroor karo

---

## Final Delivery — 5 Cheezein Zaroor:

1. GitHub repository
2. Trained model
3. requirements.txt
4. README / project report
5. Live demo link

---

> All the best! Agla project jab bhi karo, ye tips kaam aayenge.
